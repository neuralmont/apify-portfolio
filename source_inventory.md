All three are public Socrata resources. Portal metadata exposes schema and row access through the `/api/views/{id}` and `/resource/{id}.json` endpoints. Chicago’s metadata labels the license “See Terms of Use”; Seattle’s Data.gov record labels access public; Austin’s portal provides the public dataset page. The probe does not bypass authentication or use an app token.

The exact schema is fetched by the portal at runtime before any sample query. Required mappings are fatal if absent; optional mappings are reported in the per-city manifest and remain null. The checked-in mappings now reflect the saved Chicago/Seattle samples and official Austin/Chicago/Seattle metadata inspected for this pass. Raw sampled records are preserved for audit. A schema mismatch is reported as an extraction error rather than silently guessed.
